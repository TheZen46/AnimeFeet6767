# Lezione 1

SO, Sistema Operativo, serve a:
* rendere facile l'esecuzione dei programmi
* permettere la condivisione di memoria ai programmi
* consentire i dispositivi di interagire con i dispositivi

### Virtualizzazione:
Rende una risorsa fisica (CPU, memoria, disco) un'altra forma virtuale di sé stessa, una versione generalizzata, più potente e semplice da usare dell'originale. (es. 1 CPU $\rightarrow \ \infty$ CPU oppure *"memoria fisica unica"* $\rightarrow$ *"varie memorie private per programma"* )
La comunicazione tra utente, programmi e SO è attraverso le chiamate di sistema ( **system call** ).
