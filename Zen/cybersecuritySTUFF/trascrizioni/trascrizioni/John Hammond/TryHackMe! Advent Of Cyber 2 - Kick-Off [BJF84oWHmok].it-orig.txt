Poi leggeremo ancora qualcosa riguardo all'HTTPS. Una volta che il tuo computer sa dove trovare il sito web di destinazione, invia al server web una richiesta chiamata HTTP o Hypertext Transfer Protocol. Ora, questa è solo una richiesta di rete standard, ma è formattata in un modo che sia il tuo browser che il server possono comprendere. In pratica, ciò significa aggiungere alcune intestazioni alla richiesta, che la identificano come una richiesta HTTP e comunicano al server diverse informazioni sulla richiesta stessa e sul tuo browser. Tra le molte altre intestazioni, le richieste HTTP hanno sempre un metodo e una destinazione. Questi specificano cosa recuperare dal server, la destinazione, e come recuperarlo, il metodo. Il metodo più comunemente usato per recuperare informazioni è chiamato metodo get. Quando si inviano dati al server, è più comune utilizzare un metodo chiamato post. Per ulteriori informazioni sulle richieste HTTP, sui metodi e sulle intestazioni, consulta la stanza dei fondamenti web; quel link ti porterà a un'altra stanza. Una volta che il contenuto è stato recuperato dal server, il tuo browser legge il codice ottenuto e lo visualizza come pagina web. Di solito ciò significa prendere il layout della pagina da un documento HTML o HyperText Markup Language, definirne lo stile con il file CSS o Cascading Style Sheet collegato e aggiungere contenuti dinamici con uno o più file JavaScript collegati. L'HTTP ha uno svantaggio intrinseco. Ovvero, non è sicuro. Chiunque può vedere cosa stai richiedendo e cosa ti viene rimandato indietro.
