Let’s talk about security research and how it relates to minecraft. What even is security research? Well research means you are doing research. So doing science. And doing science generally means following the scientific method. The scientific method is the process by which science is carried out. The overall process involves making conjectures (or hypotheses, or guesses), deriving predictions from them as logical consequences, and then carrying out experiments based on those predictions to determine whether the original conjecture was correct. This describes hacking in general very well. Let’s make an example. Lets say you have this URL. You could make hypotheses or guess about it. For example “maybe the system has bad authorization checks on the ID number in the URL”. That’s a good theory. So if that is the case we can make a prediction. we should be able to change the ID and maybe get access to data from another user. So now we have to conduct an experiment to see if that prediction was correct. And there are two outcomes now. Either it doesn’t work, then we have to correct our initial hypotheses, and we have to come up with a new guess. Or it does work, and we confirm our hypotheses. As you can see, that scientific process works well for anything hacking related. But I think when we say security research, we specifically mean that we use this process to explore the unknown. And in our example it’s very well known that web applications might have bad authorization checks. So showing that this can happen is not really new insight.
