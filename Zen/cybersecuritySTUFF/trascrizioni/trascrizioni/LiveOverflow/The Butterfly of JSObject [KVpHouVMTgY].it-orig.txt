Ora, come fa JavaScript core a tenere traccia delle proprietà? Come sapete, le proprietà hanno dei nomi e vi si accede in qualche modo tramite quel nome o stringa, ma non sembra essere in questo oggetto. È qui che entra in gioco lo structure ID. Lo structure ID descrive sempre la struttura di un oggetto. Quindi, lo structure ID 302 descrive il layout di un oggetto con le proprietà B, C, D, E, F, G e H. Se usiamo queste proprietà, non cambia nulla. Tuttavia, se modifichiamo la struttura dell'oggetto, ad esempio aggiungendo un'altra proprietà I, JavaScript core deve creare una nuova struttura per descriverla. E ora il nostro oggetto ha lo structure ID 303.
