# Fondamenti di Informatica · notazione comune

| Oggetto | Notazione nei moduli |
|---|---|
| Naturali | $\mathbb N_0 = \{0, 1, \dots\}$, $\mathbb N = \{1, 2, \dots\}$ (come nelle slide) |
| Inclusione | $\subseteq$, stretta $\subset$ |
| Insieme delle parti | $\mathcal P(A)$ |
| Differenza, differenza simmetrica, complemento | $A \setminus B$, $A \,\Delta\, B$, $\overline A$ |
| Disposizioni, combinazioni | $D_{n,k}$, $D'_{n,k}$, $\binom{n}{k}$, $C'_{n,k}$ |
| Codice | C++17, `using namespace std;`, stringhe C (`char[]`), righe entro 80 caratteri |
| Classi | attributi privati con `_` iniziale, selettori `get…`, modificatori `set…`, `operator=` che restituisce `const T&` |
| Puntatore nullo | `nullptr` (nelle slide anche `NULL` o 0) |

Ogni programma comincia con `// file: nome.cpp`; `// segue: nome.cpp` indica la continuazione dello stesso file in un altro blocco.
