# Analisi Matematica 1B · notazione comune

| Oggetto | Notazione | Note |
|---|---|---|
| Vettori e punti di $\mathbb{R}^n$ | $x$, $v$ in carattere normale | Negli appunti sottolineati, nelle dispense in grassetto: detto una volta nel modulo 3 |
| Norma, prodotto scalare | $\lVert x\rVert$, $x \cdot y$ | – |
| Palla aperta | $B_r(x_0)$ | – |
| Interno, frontiera, chiusura | $\mathring{\Omega}$, $\partial\Omega$, $\bar{\Omega}$ | – |
| Derivate parziali | $\frac{\partial f}{\partial x_i}$, $f_{x_i}$, $f_{x_i x_j}$ | – |
| Gradiente, Hessiana | $\nabla f$, $H_f$ | – |
| Derivata direzionale | $D_v f$ o $\frac{\partial f}{\partial v}$ | – |
| Somme di Riemann | $s(f, P)$, $S(f, P)$ | Nelle dispense $s^-$, $S^+$: si toglie l'apice |
| Funzione integrale | $F_{x_0}(x) = \int_{x_0}^x f(t)\, dt$ | Nelle dispense la variabile muta è $y$: si usa $t$ |
| Somme parziali, resto | $S_N$, $R_N$ | – |
| Sistemi | $y' = f(t, y)$ | Nelle dispense anche $f(y, t)$: si uniforma |
| Logaritmo | $\ln$ | – |
| Matrice fondamentale | $W(t)$ | – |
