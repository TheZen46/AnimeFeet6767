## 1.1 Insiemi numerici

**Naturali**: $\mathbb{N} = \{0, 1, 2, 3, \dots\}$, $(\mathbb{N}_0 = \mathbb{N} \setminus \{0\})$. Somma e prodotto ✓, differenza ✗.

**Interi**: $\mathbb{Z} = \{\dots, -3, -2, -1, 0, 1, 2, 3, \dots\}$. Differenza ✓, quoziente ✗.

**Razionali**: $\mathbb{Q} = \left\{ \left[\frac{n}{m}\right] : n \in \mathbb{Z},\ m \in \mathbb{N}_0 \right\}$, con $\left[\frac{n}{m}\right] = \left[\frac{n'}{m'}\right] \iff nm' = n'm$. Quoziente ✓.

Come possiamo scrivere $\mathbb{Q}$:

$$\mathbb{Q} \ni q = c_k c_{k-1} \dots c_1 c_0 , d_1 d_2 \dots = c_k \cdot 10^k + c_{k-1} \cdot 10^{k-1} + \dots + c_1 \cdot 10 + c_0 \cdot 10^0 + d_1 \dots$$

2 casi:

1. la sequenza $d_1, d_2, \dots$ termina: $0{,}15 = \frac{15}{100} = \frac{3}{20}$; $0{,}\overline{9} = 1$ $\left(= \frac{3}{3}\right)$ [?]
2. la sequenza non termina ma si ripete: $0{,}\overline{3} = \frac{1}{3}$; $0{,}3\overline{157}$ [?], $c_0{,}dddd\dots$

**Reali**: $\mathbb{R}$. Ora $x^2 = 2$ ha esattamente due soluzioni (irrazionali): $x = \sqrt{2}$, $x = -\sqrt{2}$; $\frac{C}{2r} = \pi$.

- Si possono risolvere equazioni del tipo $x^2 = a$ con $a \in \mathbb{R}$, $a > 0$ (completezza).

**Proprietà di $\mathbb{R}$**

- proprietà algebriche: somma, prodotto, differenza, quoziente;
- ordinamento totale (si può sempre decidere chi viene prima): $(\forall x, y \in \mathbb{R}\ \ x \le y \ \vee\ y \le x)$.

## Valore assoluto o modulo

Dato $x \in \mathbb{R}$, definisco

$$|x| = \begin{cases} x & \text{se } x \ge 0 \\ -x & \text{se } x < 0 \end{cases} = \begin{cases} x & \text{se } x > 0 \\ 0 & \text{se } x = 0 \\ -x & \text{se } x < 0 \end{cases}$$

**Proprietà di $|x|$**

- $|x + y| \le |x| + |y|$ (disuguaglianza triangolare)
- $|xy| = |x| \cdot |y|$
- $\big||x| - |y|\big| \le |x - y|$

Possiamo verificarlo:

1. $|x| = |(x - y) + y| \le |x - y| + |y|$, quindi $|x| - |y| \le |x - y|$;
2. $|y| = |(y - x) + x| \le |y - x| + |x|$, con $|y - x| = |x - y|$, quindi $|y| - |x| \le |x - y|$.

Moltiplico la 2 per $-1$: $-|x - y| \le |x| - |y| \le |x - y|$, cioè $\big||x| - |y|\big| \le |x - y|$.

## Intervalli

**Def.** Dati $a, b \in \mathbb{R}$ t.c. $a \le b$:

- intervallo chiuso: $[a, b] := \{x \in \mathbb{R} : a \le x \le b\}$;
- intervallo aperto ($a < b$): $(a, b) := \{x \in \mathbb{R} : a < x < b\}$;
- intervalli semiaperti / semichiusi: $[a, b) := \{a \le x < b\}$, $(a, b] := \{a < x \le b\}$;
- intervalli illimitati: $[a, +\infty) := \{x \in \mathbb{R} : a \le x\}$ ($+\infty$ non è un numero reale).

## Sottoinsiemi limitati

**Def.** Sia $A \subseteq \mathbb{R}$ un sottoinsieme.

<!-- p. 2 -->

Diremo che:

- $a \in \mathbb{R}$ è un **minorante** di $A$ quando $a \le x \ \ \forall x \in A$;
- $b \in \mathbb{R}$ è un **maggiorante** di $A$ quando $x \le b \ \ \forall x \in A$.

Quando $A$ ammette minoranti / maggioranti diremo che $A$ è limitato inferiormente / superiormente.

**Def.** Sia $A \subseteq \mathbb{R}$. Diremo che $A$ ammette massimo (minimo) se esiste $x_0 \in A$ tale che $x \le x_0 \ \ \forall x \in A$; $x_0 = \max(A)$.

**Def.** Sia $A \subseteq \mathbb{R}$ un sottoinsieme superiormente limitato. Chiameremo **estremo superiore** di $A$ il numero reale $\sup(A) \in \mathbb{R}$ che è il più piccolo dei maggioranti di A (inferiore: che è il più grande dei minoranti).

$$\sup(A) := \min\{x \in \mathbb{R} : x \text{ è maggiorante di } A\} \qquad \inf(A) := \max\{x \in \mathbb{R} : x \text{ è minorante di } A\}$$

**Osservazione.** $A \subseteq \mathbb{R}$ sottoinsieme sup. limitato. Allora $S = \sup(A)$ è caratterizzato dalle seguenti proprietà:

1. $x \le S \ \ \forall x \in A$, cioè $S$ è maggiorante di $A$;
2. se $z \ge x \ \ \forall x \in A$, allora $z \ge S$: se $z$ è maggiorante di $A$ allora $z \ge S$, ovvero $S$ è il più piccolo tra i maggioranti di $A$. $(\forall x \in A\ \ z \ge x) \Rightarrow z \ge S$;

$z < S \Rightarrow (\exists x \in A,\ z < x)$, con $z$ numero reale.

**Assioma di [illeggibile]**: $\mathbb{R}$ è completo. Tutti i sottoinsiemi di $\mathbb{R}$ sup. limitati ammettono estremo superiore.

## Applicazione della completezza

Risolvo $x^2 = 2$: $\{q \in \mathbb{Q} : q^2 < 2\}$ è superiormente limitato.

## 2 Funzioni

### 2.1 Definizione

**Def. (funzione)** Dati due insiemi $X$, $Y$, una **funzione** definita su $X$, detto dominio, e a valori in $Y$, detto codominio, è una legge che associa ad ogni elemento $x \in X$ un elemento $y \in Y$ $(= f(x))$: $f : X \to Y$, $x \mapsto f(x)$.

Una funzione $f$ definita **in** $X$ e a valori in $Y$, detto codominio, è una legge che ad ogni elemento $x \in X$ associa **al più** un elemento di $Y$.

$\operatorname{dominio}(f) = \{x \in X : f \text{ associa ad } x \text{ un elemento di } Y\}$, $\quad f : \operatorname{dom}(f) \subseteq X \to Y$.

**Def. (immagine)** Data una funzione $f : X \to Y$, si definisce l'immagine di $f$ come $\operatorname{im}(f) := \{y \in Y : \exists x \in X\ (\operatorname{dom}(f)),\ f(x) = y\}$.

**Def. (grafico)** Data una funzione $f : X \to Y$, si definisce il grafico di $f$ come $\{(x, f(x)) \in X \times Y : x \in X\} = \Gamma(f)$ ($\Gamma$ = gamma).

**Esempi**

- $f : \{1, 2, 3, 5\} \subseteq \mathbb{N} \to \{a, b, c, d, \dots\}$ (alfabeto): $1 \mapsto b$, $2 \mapsto c$, $3 \mapsto d$, $5 \mapsto b$. $\operatorname{im}(f) = \{b, d, f\}$, $\Gamma(f) = \{(1, b), (2, f), (3, d), (5, b)\}$.

- $f : \mathbb{R} \to \mathbb{R}$, $x \mapsto |x|$. $\operatorname{im}(f) = \{|x| : x \in \mathbb{R}\} = \{x \ge 0\}$; $\Gamma(f) = \{(x, |x|) : x \in \mathbb{R}\}$.
