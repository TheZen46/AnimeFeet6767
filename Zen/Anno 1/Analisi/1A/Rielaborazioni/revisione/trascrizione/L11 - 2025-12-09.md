## 7. Sviluppi di Taylor

### 7.1 Formula di Taylor

**Def. (polinomio di Taylor)** $n \in \mathbb{N}$, $f$ derivabile $n$ volte in $x_0$. Si dice **polinomio di Taylor** di $f$ in $x_0$ all'ordine $n$ il polinomio

$$Tf_{n,x_0}(x) := \frac{1}{0!} f(x_0) + \frac{1}{1!} f'(x_0)(x - x_0) + \dots + \frac{1}{n!} f^{(n)}(x_0)(x - x_0)^n = \sum_{k=0}^{n} \frac{1}{k!} f^{(k)}(x_0)(x - x_0)^k.$$

Quando $x_0 = 0$, si usa anche il nome **polinomio di Mac Laurin**.

**Oss.** $Tf_{0,x_0}(x) = f(x_0)$; $\quad Tf_{1,x_0}(x) = f(x_0) + f'(x_0)(x - x_0)$.

**Th. (formula di Taylor con resto di Peano)** Sia $f$ derivabile $n$ volte in $x_0$. Allora vale

$$f(x) = Tf_{n,x_0}(x) + o\left((x - x_0)^n\right), \quad x \to x_0.$$

**Dim.** Vogliamo usare il Th. di de l'Hôpital per verificare che

$$\lim_{x \to x_0} \frac{f(x) - Tf_{n,x_0}(x)}{(x - x_0)^n} = 0.$$

Per prima cosa confronto le derivate di $f$ e di $Tf_{n,x_0}$ in $x_0$:

- $Tf_{n,x_0}^{(0)}(x_0) = f(x_0) = f^{(0)}(x_0)$;
- $Tf_{n,x_0}^{(1)}(x_0) = \left(f(x_0) + f'(x_0)(x - x_0) + \dots\right)^{(1)}(x_0) = 0 + f'(x_0) + 0 = f'(x_0)$;
- $Tf_{n,x_0}^{(2)}(x_0) = \left(f(x_0) + f'(x_0)(x - x_0) + \frac{1}{2} f''(x_0)(x - x_0)^2 + \dots\right)^{(2)}(x_0) = 0 + 0 + f''(x_0) + 0 = f^{(2)}(x_0)$;
- …
- $Tf_{n,x_0}^{(n)}(x_0) = \left(\dots + \frac{1}{n!} f^{(n)}(x_0)(x - x_0)^n\right)^{(n)}(x_0) = 0 + \frac{1}{n!} f^{(n)}(x_0) \cdot n! = f^{(n)}(x_0)$.

Consideriamo questo: per $k = 0, \dots, n-1$

$$\lim_{x \to x_0} \left(f - Tf_{n,x_0}\right)^{(k)}(x) = \lim_{x \to x_0} f^{(k)}(x) - \lim_{x \to x_0} Tf_{n,x_0}^{(k)}(x) = f^{(k)}(x_0) - Tf_{n,x_0}^{(k)}(x_0) = 0$$

(per la verifica precedente), poiché $f^{(k)}$ è derivabile, quindi continua in $x_0$, e poiché i polinomi sono funzioni continue.

$$\begin{aligned} \lim_{x \to x_0} \frac{(f - Tf_{n,x_0})(x)}{(x - x_0)^n} &\overset{H}{=} \lim_{x \to x_0} \frac{(f - Tf_{n,x_0})^{(1)}(x)}{n (x - x_0)^{n-1}} \overset{H}{=} \lim_{x \to x_0} \frac{(f - Tf_{n,x_0})^{(2)}(x)}{n(n-1)(x - x_0)^{n-2}} = \dots \\ &\overset{H}{=} \lim_{x \to x_0} \frac{(f - Tf_{n,x_0})^{(n-1)}(x)}{n(n-1) \cdots 2\, (x - x_0)} \overset{H}{=} \lim_{x \to x_0} \frac{f^{(n-1)}(x) - f^{(n-1)}(x_0) - f^{(n)}(x_0)(x - x_0)}{n! \cdot (x - x_0)} \\ &= \frac{1}{n!}\left(\lim_{x \to x_0} \frac{f^{(n-1)}(x) - f^{(n-1)}(x_0)}{x - x_0} - f^{(n)}(x_0)\right) = 0 \end{aligned}$$

(per la definizione della derivata $n$-esima di $f$, il limite vale $f^{(n)}(x_0)$).

**Th. (formula di Taylor con resto di Lagrange)** Sia $f$ derivabile $n$ volte in un intorno $I$ di

<!-- p. 2 -->

un certo punto $x_0$, con derivata $n$-esima $f^{(n)}$ continua su $I$ ($f \in C^n(I)$). Inoltre, sia $f$ derivabile $n + 1$ volte in $I \setminus \{x_0\}$. Allora, per ogni $x \in I \setminus \{x_0\}$ esiste $\bar{x}$ compreso tra $x_0$ e $x$ tale che

$$f(x) = Tf_{n,x_0}(x) + \underbrace{\frac{1}{(n+1)!} f^{(n+1)}(\bar{x})(x - x_0)^{n+1}}_{\text{resto di Lagrange}}.$$

**Esempi (sviluppi di Taylor di funzioni notevoli)**

- $e^x$ all'ordine $n$ in 0: $e^x = Te^x_{n,0}(x) + o(x^n)$ [?].

$(e^x)^{(1)} = e^x$, $(e^x)^{(2)} = e^x$, $(e^x)^{(3)} = e^x$, …, valutate in $x = 0$ valgono 1.

$$Te^x_{n,0}(x) = \sum_{k=0}^{n} \frac{1}{k!} (e^x)^{(k)}(0)\, x^k = 1 + x + \frac{1}{2} x^2 + \frac{1}{3!} x^3 + \dots + \frac{1}{n!} x^n$$

- $\ln(1 + x)$ all'ordine $n$ in 0: $\ln(1 + x) = T\ln(1+x)_{n,0}(x) + o(x^n)$.

$$\ln(1+x)^{(0)}(0) = 0, \quad \ln(1+x)^{(1)}(0) = \left(\frac{1}{1+x}\right)(0) = 1, \quad \dots, \quad \ln(1+x)^{(2)}(0) = \left(\frac{-1}{(1+x)^2}\right)(0) = -1$$

$$T\ln(1+x)_{n,x_0}(x) = \sum_{k=1}^{n} \frac{(-1)^{k-1}}{k} x^k = x - \frac{1}{2} x^2 + \frac{1}{3} x^3 + \dots + \frac{(-1)^{n-1}}{n} x^n$$

$$\ln(1 + x) = x - \frac{1}{2} x^2 + \dots + o(x^n), \quad x \to 0$$

- $\sin(x)$ all'ordine $2n$ in 0:

$\sin^{(1)} \to \cos$, $\sin^{(2)} \to -\sin$, $\sin^{(3)} \to -\cos$, $\sin^{(4)} \to \sin^{(0)}$; $\quad \sin^{(0)}(0) = 0$, $\sin^{(1)}(0) = 1$, $\sin^{(2)}(0) = 0$, $\sin^{(3)}(0) = -1$.

$$\sin^{(k)}(0) = \begin{cases} 0 & \text{se } k \text{ pari} \\ (-1)^l & \text{se } k = 2l + 1 \text{ è dispari } (l \text{ numero naturale}) \end{cases}$$

$$T\sin_{2n,0}(x) = \sum_{k=0}^{2n} \frac{1}{k!} \sin^{(k)}(0)\, x^k = \sum_{l=0}^{n-1} \frac{1}{(2l+1)!} (-1)^l x^{2l+1}$$

$$\sin(x) = \sum_{l=0}^{n-1} \frac{(-1)^l}{(2l+1)!} x^{2l+1} + o(x^{2n}) = x - \frac{1}{6} x^3 + \frac{1}{120} x^5 + \dots + \frac{(-1)^{n-1}}{(2n-1)!} x^{2n-1} + o(x^{2n})$$

$T\sin_{2n-1,0} = T\sin_{2n,0}$.

**Prop. (unicità del polinomio di Taylor)** Sia $f$ derivabile $n$ volte in $x_0$ e sia $P$ un polinomio di grado $\le n$. Se vale $f(x) = P(x) + o\left((x - x_0)^n\right)$, $x \to x_0$, allora $P = Tf_{n,x_0}$, cioè è il polinomio di

<!-- p. 3 -->

Taylor di $f$ in $x_0$ all'ordine $n$.

Utilizziamo questa proposizione per costruire sviluppi di Taylor di funzioni complicate (somma, prodotto, quoziente, composta, inversa).

**Somma.** $f$, $g$ derivabili $n$ volte in $x_0$. Vorremmo sviluppare $f + g$ all'ordine $n$ in $x_0$.

$$f(x) = Tf_{n,x_0}(x) + o\left((x - x_0)^n\right), \quad g(x) = Tg_{n,x_0}(x) + o\left((x - x_0)^n\right), \quad x \to x_0$$

$$f(x) + g(x) = \underbrace{Tf_{n,x_0}(x) + Tg_{n,x_0}(x)}_{\text{grado} \le n\ \Rightarrow\ P(x)} + o\left((x - x_0)^n\right), \quad x \to x_0$$

Deduciamo dalla proposizione che $T(f+g)_{n,x_0} = Tf_{n,x_0} + Tg_{n,x_0}$.

**Prodotto.** $f$, $g$ derivabili $n$ volte in $x_0$. Allora $f \cdot g$ è derivabile $n$ volte in $x_0$.

$$f(x) = Tf_{n,x_0}(x) + o\left((x - x_0)^n\right), \quad g(x) = Tg_{n,x_0}(x) + o\left((x - x_0)^n\right), \quad x \to x_0$$

$$f(x) \cdot g(x) = Tf_{n,x_0}(x) \cdot Tg_{n,x_0}(x), \quad x \to x_0$$

$$Tf_{n,x_0}(x) \cdot Tg_{n,x_0}(x) = \underbrace{P(x)}_{\text{parte di grado} \le n} + \underbrace{R(x)}_{\text{resto di grado} \ge n+1}$$

**Quoziente.** $f$, $g$ derivabili $n$ volte in $x_0$, $g(x_0) \ne 0$. Allora $f/g$ è derivabile $n$ volte in $x_0$.

$$\frac{f(x)}{g(x)} = \underbrace{T\left(\tfrac{f}{g}\right)_{n,x_0}(x)}_{P(x)} + o\left((x - x_0)^n\right), \quad x \to x_0$$

$$f(x) = \frac{f(x)}{g(x)} \cdot g(x) = P(x)\, g(x) + o\left((x - x_0)^n\right) \cdot g(x) = P(x)\, g(x) + o\left((x - x_0)^n\right)$$

Sostituisco gli sviluppi di $f$ e $g$:

$$Tf_{n,x_0}(x) + o\left((x - x_0)^n\right) = P(x)\left(Tg_{n,x_0}(x) + o\left((x - x_0)^n\right)\right) + o\left((x - x_0)^n\right)$$

dove $P(x) \cdot o\left((x - x_0)^n\right) = o\left((x - x_0)^n\right)$.
