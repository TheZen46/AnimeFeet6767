Come individuiamo le soluzioni? Però NON otteniamo la sintesi MINIMA ma la sintesi QUASI MINIMA.

Mappa (riga $\bar{A}$: 1, I; riga A: 1, 0). La I corrisponde a due mappe.

Primo tentativo: $U = \bar{I}(\dots) + I(\dots) = \bar{I}(\bar{B}) + I(\bar{B} + \bar{A})$. Però NON HA SENSO, perché prendo due volte celle che abbiamo già preso nell'altra mappa.

Mappa con I = 0 (riga $\bar{A}$: 1, 0; riga A: 1, 0) → $\bar{B}$. Mappa di I (riga $\bar{A}$: –, 1; riga A: –, 0) → $\bar{A}$.

$U = \bar{B} + I(\bar{A})$: non ci sono $\bar{I}$ da moltiplicare perché sono già inclusi nella mappa.

Complichiamo: mappa 2×4 (riga $\bar{A}$: 1 1 y y; riga A: 1 x 0 0).

- Tutti gli x e y = 0 (riga $\bar{A}$: 1 1 0 0; riga A: 1 0 0 0) → $\bar{A}\bar{B} + \bar{B}\bar{C}$.
- x = 1 (riga $\bar{A}$: – – 0 0; riga A: – 1 0 0) → $\bar{B}$.
- y = 1 (riga $\bar{A}$: – – 1 1; riga A: – 0 0 0) → $\bar{A}$.

$$U = \bar{A}\bar{B} + \bar{B}\bar{C} + X(\bar{B}) + Y(\bar{A})$$

**Le regole per fare questi esercizi:**

1. si individuano le variabili riportate;
2. si fa la mappa con tutte le variabili riportate = 0 e le mappe con una variabile riportata per volta = 1 (0 → 0, – → –, 1 → –);
3. si sommano (OR) le mappe, ognuna con la sua variabile riportata che la moltiplica (AND).

Mappa 4×4 (righe AC, colonne BD):

| | 00 | 01 | 11 | 10 |
|---|---|---|---|---|
| 00 | 1 | 1 | xy | y |
| 01 | 1 | x | 0 | 0 |
| 11 | 0 | – | – | 0 |
| 10 | 0 | x | 0 | 0 |

Le variabili riportate sono 3: x, y, xy. Si fanno le mappe per xy = 1, tutte = 0, x = 1, y = 1.
