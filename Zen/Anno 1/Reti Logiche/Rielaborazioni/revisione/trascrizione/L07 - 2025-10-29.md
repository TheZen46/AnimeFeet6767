**Esercizio 1.** $Y = \bar{A}\bar{B}\bar{C} + \bar{A}B\bar{C} + AB\bar{C}$

$= \bar{A}\bar{B}\bar{C} + \bar{A}B\bar{C} + \bar{A}B\bar{C} + AB\bar{C} = \bar{A}\bar{C}(\bar{B} + B) + B\bar{C}(\bar{A} + A) = \bar{A}\bar{C} + B\bar{C} = \bar{C}(\bar{A} + B)$

Mappa (riga $\bar{A}$: 1 0 0 1; riga A: 0 0 0 1) → $\bar{A}\bar{C} + B\bar{C}$.

**Esercizio 2.** $Y = \bar{A}\bar{B}\bar{C} + \bar{A}B\bar{C} + \overline{AB\bar{C}}$ [?]

Leggi di De Morgan: $\bar{A}\bar{B}\bar{C} + \bar{A}B\bar{C} + \bar{A} + \bar{B} + C$

$\bar{A}\bar{C}(\bar{B} + B) + \bar{A} + \bar{B} + C = \bar{A}\bar{C} + \bar{A} + \bar{B} + C = \bar{A}(\bar{C} + 1) + \bar{B} + C = \bar{A} + \bar{B} + C$: questa è la sintesi minima.

Tabella A B C | Y: tutti 1 tranne 110. Mappa (riga $\bar{A}$: 1 1 1 1; riga A: 1 1 1 0) → $\bar{A} + \bar{B} + C$.
