Un treno si muove a $100\frac{km}h$.
Un passeggero di muove a $4\frac{km}h$ nel verso opposto alla velocità del treno.
A che velocità si muove il passeggero rispetto al binario?

$\text{Treno}\equiv O'$
$\text{Binario}\equiv O$
$\text{Passeggero}\equiv P$

$\begin{cases}v_{0x}=100\\v_{0y}=0\end{cases}\ \ \ \ \ \ \ \text {Velocità di }O'\text{ rispetto a }O$

$\begin{cases}{v_{x'}}^P=-4\\{v_{y'}}^P=0\end{cases}\ \ \ \ \ \ \ \text {Velocità di }P\text{ rispetto a }O'$

$\begin{cases}{v_x}^P=v_{0x}+{v_{x'}}^P=100-4=96\frac{km}h\\{v_x}^P=v_{0y}+{v_{y'}}^P=0\end{cases}\ \ \ \ \ \ \ \ \text {Velocità di }O'\text{ rispetto a }O$

$\frac{d{v_x}^P}{dt}={a_x}^P=0+\frac{d{v_{x'}}^P}{dt}={a_{x'}}^P$
