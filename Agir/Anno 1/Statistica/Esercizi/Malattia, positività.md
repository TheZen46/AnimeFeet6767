Una malattia rara colpisce $1\%$ della popolazione viene effettuato un test su un campione di $1000$ persone.

Il test ha una percentuale di $\begin{array}{l}\text{falsi positivi al }10\%\\\text{falsi negativi al }20\%\end{array}$

Considerate le due variabili
$x_l=\text{malato, sano}$
$y_l=\text{positivo, negativo al test}$

Se sono positivo al test mi devo preoccupare?

| $\begin{array}{c}&y_l\\x_l&\end{array}$ | $P$   | $N$   |     | $n_{i:}$ |
| --------------------------------------- | ----- | ----- | --- | -------- |
| $M$                                     | $8$   | $2$   |     | $10$     |
| $S$                                     | $99$  | $891$ |     | $990$    |
|                                         |       |       |     |          |
| $n_{:j}$                                | $107$ | $893$ |     | $1000$   |

$i=1,2\text{ numero di righe}$
$j=1,2\text{ numero di colonne}$

$f_{M\mid P}=\frac8{107}\approx7\%$
$f_{S\mid P}=\frac{99}{107}\approx93\%$
Con test positivo, si ha il $93\%$ di probabilità di essere sani
