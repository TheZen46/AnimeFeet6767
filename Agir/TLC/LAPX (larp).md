- **LAPF**: link access procedure for frame relay 
- **LAPD:** link access procedure for d-channel 
- **LAPM**: link access procedure for modems 
- **LAPB**: link access procedure balanced 


- **LAPF**: frame relay, formatta frame, rilevamento errori, no correzione automatica.
- **LAPD**: ISDN, canale D, segnalazione, connessioni rete, HDLC.
- **LAPM**: modem, V.42, correzione errori, ARQ, finestra scorrevole.
- **LAPB**: X.25, punto a punto, riscontro positivo, ritrasmissione.
